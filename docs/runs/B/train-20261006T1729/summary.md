# B-only · train（2024 训练 / 2025 验证）

- 方案：B-only（稳健池 + 客观多因子）
- 阶段：train（拟合/选型）
- 命令：`node scripts/optimize-factors.js --train 2024 --val 2025 --narrow`
- 网格：45 个配置（只搜 midRev / upShadow / turnStd；reversal/q/event 固定）
- 数据：2024-01 ~ 2025-12；只用 ≤ 决策日的日K / 财务(`notice<=asOf`) / 公告。**未用 2026**。

## 结果（T+10 相对沪深300 超额 %）

- 当前引导权重（2026 拟合）：**训练均 -0.56 / 验证均 -0.00**。
- 按「训练最差月最优」选出：`rv0.2 mr0.1 sh0.4 ts0.5` → **训练均 -0.11 / 验证均 +0.12 / 验证最差 -1.62**。
- **所有配置的训练均都是负的**（-0.11 ~ -1.07）。
- **训练最差月 vs 验证均 的相关系数 = -0.803** → 「按训练集选优」是反向的（越优化越糟）。

## 结论

1. **B 在 2024/2025 没有可证明的正超额**：即便用当前成分股（**含幸存者偏差、偏乐观**），
   2024 训练均仍为负；验证均仅 ~0。
2. **网格选型无效**：训练-验证相关系数 -0.803，选出来的配置不可信。
3. **结构性原因（推测）**：候选池含创业板/科创板（中小盘），而基准是沪深300；2024 大盘强、
   中小盘弱 → 结构性跑输基准。
