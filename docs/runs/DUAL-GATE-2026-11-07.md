## 改动
- `web/lib/recommend.js` `pickChain`：`tilt>=thr → B`（进攻），否则 `A`（防御）；取不到 tilt / 阈值非法 → A。
- `web/lib/factors.js`：新增 `regimeTiltDetail` + `isTiltDataIssue`，区分「弱市合法 0」与缺 K 线/短窗/坏收盘。
- `web/scripts/eval-ab-combo.js`：组合评估统一调用 `pickChain`，避免评估与线上口径漂移。
- 单测：`web/test/recommend.test.js` 门控期望值与刷新用例按新映射更新。
