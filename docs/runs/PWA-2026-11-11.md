# PWA / 移动端改造（2026-11-11）

## 目标

iPhone「添加到主屏幕」后以 standalone 全屏打开（不再显示 Safari 地址栏），同时保证 390×844 / 430×932 下各页面无横向溢出、表格可读、点击区可用。

只动 PWA 壳与响应式 CSS，不改业务逻辑、数据与视觉风格。

## 改动

| 文件 | 内容 |
| --- | --- |
| `web/public/manifest.webmanifest` | 新增真实静态 manifest：`name=股票速览`、`short_name=股票`、`start_url=/`、`scope=/`、`display=standalone`、主题/背景色、192/512 + maskable 图标 |
| `web/public/icons/*` | 新增 192/512、maskable 192/512、180×180 apple-touch-icon 与 SVG 源 |
| `web/index.html` | 补 `link[rel=manifest]`、`apple-mobile-web-app-capable/status-bar-style/title`、apple-touch-icon、theme-color |
| `web/server.js` | MIME 增加 `.webmanifest → application/manifest+json; charset=utf-8`，线上不再被 SPA fallback 吞掉 |
| `web/public/sw.js` | 最小 SW：只缓存 app shell（`/`、manifest、图标），导航 network-first；带 `VERSION`，升级时清旧缓存；不缓存 hashed JS/CSS |
| `web/src/main.tsx` | 生产环境注册 SW；`/?sw=off` 一键注销并清空 `stock-shell-*` 缓存 |
| `web/src/styles.css` | ≤640px：顶栏两行（页签横向滑动）、表格/板块榜/持仓横向容器、推荐卡片换行、点击区 44px、safe-area |
| `web/src/components/MarketTabs.tsx` | 当前页签自动滚入可视区（手机横向页签） |
| `web/src/components/KLineChart.tsx` | K 线 tooltip 按实际宽度夹在卡片内，避免贴边时撑宽页面 |
| `web/src/components/LabView.tsx` | 实验 tables 包横向滚动容器 |

## 验收结果

### 1. Manifest

```bash
curl -sSI https://stock.zxlumen.cn/manifest.webmanifest
# HTTP/2 200
# content-type: application/manifest+json; charset=utf-8
```

本地实测：

```text
manifest  200 application/manifest+json; charset=utf-8 978 bytes
icon192   200 image/png 12874 bytes
apple180  200 image/png 12186 bytes
sw.js     200 text/javascript; charset=utf-8 2581 bytes
```

manifest 关键字段：`display=standalone`、`start_url=/`、`scope=/`、`icons=4`（2 any + 2 maskable）。

### 2. 移动端 Playwright

Chromium + WebKit，各跑 iPhone 13（390×844）与 430×932：

- 页面：首页（沪深港/美股）、板块、推荐、模拟持仓、策略实验室、基金、个股详情（共 7 页 × 2 视口 × 2 引擎 = 28 次）
- 结果：`document.scrollWidth == document.documentElement.clientWidth`（390/390、430/430），**0 页面横向溢出、0 console error**
- 交互补充：板块详情、基金详情、站长设置弹窗均无横向溢出；K 线浮窗在鼠标贴右边缘时也不撑宽页面
- 截图：`/tmp/opencode/stock-audit/final2/*.png`、`/tmp/opencode/stock-audit/webkit/*.png`

### 3. 桌面 1440 回归

- 1440×900：首页/推荐/持仓/基金 `scrollWidth=1440`，0 console error
- 与改动前截图逐像素对比：推荐、持仓、基金 **0 差异**；首页仅新闻列表内容随时间变化，布局一致

### 4. PWA 壳

- `link[rel=manifest]` → `/manifest.webmanifest`
- `apple-mobile-web-app-capable=yes`
- `apple-mobile-web-app-status-bar-style=black-translucent`
- `apple-mobile-web-app-title=股票`
- `apple-touch-icon=/icons/apple-touch-icon.png`
- SW 激活 scope `/`，缓存键 `stock-shell-v1`，缓存条目仅：
  `/`、`/manifest.webmanifest`、`/icons/icon-192.png`、`/icons/icon-512.png`
- 访问 `/?sw=off` 后：`registrations=0`，`stock-shell-*` 缓存为空

## 老板 3 步 iOS 验收

1. iPhone Safari 打开 `https://stock.zxlumen.cn`。
2. 点底部「分享」→「添加到主屏幕」→ 名称保持「股票」→ 添加。
3. 从主屏幕图标打开：应全屏显示，**顶部无 Safari 地址栏**；左右滑动页面不应出现横向滚动（页签/表格自身可左右滑）。

> 若主屏仍打开旧版本：Safari 访问 `https://stock.zxlumen.cn/?sw=off` 一次，再重新从主屏打开；之后正常访问会自动重新注册 SW。
