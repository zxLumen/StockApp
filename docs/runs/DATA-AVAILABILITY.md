## 三、已知局限（训练/评估结论里必须注明）

1. **幸存者偏差**：宇宙取自**当前**成分股（`universe-stable` / `universe-amount-10`）回溯历史，
   所有历史成绩**偏乐观**。
2. **新闻覆盖偏薄**：2024~2025 的新闻回补**只有单列 347**（2026 才是多列），
   逐日条数少于 2026 → A 链路在旧窗口的信息量**弱于** 2026。
3. **日K 上限 1023 根**：最早 2022-07；2024 训练回看充足，但更早不做。
4. **公告按天回补**：`flush` 在整段结束时落盘；2024-02/10 等月天数略少（接口/页面波动），非交易因素。
5. 2023-12 起才有新闻；2024 训练窗口内**不缺月**（2024-01~12 齐）。

## 四、复现命令

```bash
cd web
node scripts/refetch-klines.js --dry-run          # 先看要补多少
node scripts/refetch-klines.js --limit 1023       # 重抓日K
node scripts/archive-history.js --from 2024-01-01 --to 2024-12-31 --ann-only --ann-byday   # 公告(按天)
node scripts/archive-history.js --from 2024-04-01 --to 2024-04-15 --news-only --cols 347 --col-start 347:458  # 新闻(列347)
```
