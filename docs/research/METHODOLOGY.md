# 指标口径

## 1. 逐票基准

- **买入**：新推荐 `entryAnchor='effective'` → **生效日开盘价**；旧推荐 → 生成日（basisDate）快照价/收盘。
- **卖出**：`entry + ai.holdDays` 那个交易日的**开盘价**（开买开卖）；旧口径用收盘。
- **未走完持有周期**：用最新收盘 **MTM**，并标记 `done=false`。
- **至今**：`最新收盘 / 买入价 - 1`（不卖），与推荐页「推荐日至今」同口径。

## 2. 聚合

- **逐票等权**：所有 (日期, 股票) 交易等权；主指标是均值 + bootstrap 95% CI。
- **每日 cohort**：当天 10 只的等权均值；用于看逐日路径，**不是组合收益**。
- **严禁**：把重叠持有期的每日 cohort 收益直接复利。B 平均持有 3~6 天、A 12~45 天，逐日 cohort 高度重叠，复利会重复计算（会得到 -84% 这类假数）。
- 组合收益请看生产持仓页的**金额法**：`(已实现+浮动)/累计买入`，那是另一套口径。

## 3. 基准

| 链路 | 主基准 | 参考基准 |
|---|---|---|
| A（大市值/长持） | 沪深300 | 中证800 |
| B（小盘成长/短持） | 创业板指 | 中证1000 / 科创50 |
| dual | 按当日 `regime.chain` 取 A/B 的基准 | — |

- `均超额 = 逐票收益 - 同窗口基准收益`（不是“整月收益 - 整月指数”）。
- **β/α**：逐票 OLS `ret_i = α + β * bench_i`；α 是同期、非年化。R² 低时不要过度解读。

## 4. 成本

- 成本敏感性：单边 `0 / 10 / 15 / 20 bps`，往返 = ×2（即 0 / 0.2% / 0.3% / 0.4%）。
- 未计入：涨跌停/停牌不可成交、整手约束、资金约束、分红、冲击成本。

## 5. 统计

- 每链 190 笔（19 个生效日 × 10），但只有 ~20 个交易日、持有期重叠 → 有效样本远小于 190。
- 给 bootstrap 95% CI；**尚未**做 Deflated Sharpe / 多重检验校正。
- 结论只在 holdout 区间内有效，不外推。

## 6. 已知偏差

- **幸存者偏差**：universe 是当前成分股回溯。
- **A 的未了结比例高**：A 的持有 12~45 天，190 笔里只有 47 笔走完；A 的“已了结”才是已实现，其余是 MTM。
- **AI 动态退出**：本轮没有 11 月的 PIT actions，未评估。
- **LLM 版本**：A 链的模型/提示词版本会随线上变化；评估只代表这一段。
